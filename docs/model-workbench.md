# 3D 模型工作台

首版展示和下载同源的概念键盘零件。当前是外观试样，不是经过硬件适配或实际打印验证的键盘套件。

## 运行

使用 Node.js 22.12+（或 24/26）与 npm：

```bash
npm ci
npm run dev
```

打开终端输出的本地地址。拖动旋转、滚轮缩放、右键平移；拖动拆解滑杆查看层级。可点击模型或列表选择零件、逐件隐藏、查看线框、恢复全部显示和重置视角。

```bash
npm test
npm run build
npm run export:stl
```

构建生成 `dist/` 静态网站，可部署到静态服务器。单独导出生成 `exports/stl/` 中的 15 个独立二进制 STL，以及 `exports/manifest.json` 和 `public/codex-micro-stl.zip`。生成物不纳入 Git，由源码重建。网页支持所选零件下载和整套 ZIP 下载。

## 模型与导出约定

- [几何源文件](../web/model.js) 定义零件 ID、几何、组装位置、颜色、拆解层级和说明；[网页入口](../web/main.js) 负责交互，[导出脚本](../scripts/model/export.mjs) 在 Node 中使用同一几何源。
- Z 向上，长度单位毫米。外形草案为 110 × 132 mm，底板 3 mm、围框 14 mm、上盖 3 mm。均为设计假设，不是参考产品的实测尺寸。
- 每个 STL 使用零件局部坐标并落到 Z=0；不会把网页拆解位移写进打印文件。STL 自身不记录单位，在切片器选择 mm。
- 上盖按外观控件轮廓开孔，单边预留 0.5 mm；不是机械轴定位板。键帽、旋钮和摇杆为实心占位件，没有连接柱或轴孔。
- 底板、围框、上盖为三个独立样件，目前没有螺丝柱、卡扣、PCB 支撑、USB 开孔及麦克风结构，不能直接装成可用键盘。
- 模型结构由参数和循环构造，改动尺寸需同步评估壁厚、孔位、间隙。当前不提供网页在线改尺寸或 STEP/B-rep CAD。

## 验证范围

自动测试对全部 STL 回读，检查有限坐标、每条边恰好连接两个面、边方向一致、正体积以及打印底面 Z=0。对齐矩形孔的三角化会产生 T 接点，几何生成器会分割对应边，保证邻接完整。

这些检查不代替切片和实物验证。打印前在切片器确认尺寸、摆放、支撑和最小特征；材料收缩、打印间隙、结构强度及装配需要样件测试。下一步确定轴体、PCB、编码器、接口与紧固方式后再完善工程结构。
