# 3D 模型工作台

首版展示和下载同源的概念键盘零件。当前是外观试样，不是经过硬件适配或实际打印验证的键盘套件。

## 运行

使用 Node.js 22.12+（或 24/26）与 npm：

```bash
npm ci
npm run dev
```

打开终端输出的本地地址。拖动旋转、滚轮缩放、右键平移；拖动拆解滑杆查看层级。可点击模型或列表选择零件、逐件隐藏、查看线框、恢复全部显示和重置视角。

```bash
npm test
npm run build
npm run export:stl
```

构建生成 `dist/` 静态网站，可部署到静态服务器。单独导出生成 `exports/stl/` 中的 18 个独立二进制 STL，以及 `exports/manifest.json` 和 `public/codex-micro-stl.zip`。生成物不纳入 Git，由源码重建。网页支持所选零件下载和整套 ZIP 下载。

## 模型与导出约定

- [几何源文件](../web/model.js) 定义零件 ID、几何、组装位置、颜色、拆解层级和说明；[网页入口](../web/main.js) 负责交互，[导出脚本](../scripts/model/export.mjs) 在 Node 中使用同一几何源。
- Z 向上，长度单位毫米。当前外形草案为 110 × 110 mm，底板 3 mm、围框 7 mm、低位轴体定位板 1.5 mm。均为设计假设，不是参考产品的实测尺寸。
- 每个 STL 使用零件局部坐标并落到 Z=0；不会把网页拆解位移写进打印文件。STL 自身不记录单位，在切片器选择 mm。
- 低位定位板按轴体位置开 14.2 mm 方孔，孔宽与板厚仍待实物验证。键帽、旋钮和摇杆为实心占位件，没有连接柱或轴孔。
- 底板、围框、定位板为三个独立样件，目前没有螺丝柱、卡扣、PCB 支撑、USB 开孔及麦克风结构，不能直接装成可用键盘。
- 模型结构由参数和循环构造，改动尺寸需同步评估壁厚、孔位、间隙。当前不提供网页在线改尺寸或 STEP/B-rep CAD。

## 验证范围

自动测试对全部 STL 回读，检查有限坐标、每条边恰好连接两个面、边方向一致、正体积以及打印底面 Z=0。对齐矩形孔的三角化会产生 T 接点，几何生成器会分割对应边，保证邻接完整。

这些检查不代替切片和实物验证。打印前在切片器确认尺寸、摆放、支撑和最小特征；材料收缩、打印间隙、结构强度及装配需要样件测试。下一步确定轴体、PCB、编码器、接口与紧固方式后再完善工程结构。

## 历史 v0.2 外观与电子布局（已由 v0.3 飞线方案替代）

外壳使用圆角轮廓，键帽增加倒角；展示增加按键字符、状态灯窗、旋钮滚花、摇杆防滑环。圆角和键帽倒角进入同源 STL；字符、灯窗、滚花与丝印属于网页渲染细节，不包含在 STL 中。

新增 16 个电子占位件：PCB、10 个机械轴体、编码器、摇杆模块、USB-C、主控和电源芯片。PCB 展示焊盘、固定孔、丝印与示意走线；没有电路网表和可制造 PCB 数据。界面可切换“仅看电子层”，标注跟随旋转和拆解更新，点击标注查看对应说明。完整组装时默认不显示内部标注，拆解或隐藏上盖后显示。

所有电子位置、尺寸与外形仅用于布局交流，不能视为供应商尺寸或已通过装配检查。没有选择集成麦克风或电池方案，因此没有虚构其确定安装位置。电子件设为不可打印，网页禁止单件 STL 导出，整套 ZIP 仍仅包含 15 个外观打印试样。

任务键 1–6 在零件列表中归为默认折叠的“任务键组”。展开后可选择单键、控制显隐和下载；组复选框控制六个键的显隐，部分隐藏时显示中间态。点击模型中的任务键会自动展开分组。分组只改变展示层级，不合并打印几何；命令键和电子轴体仍独立列出。


## v0.3 手工飞线结构（架构沿用，布局由 v0.4 更新）

按用户确定的方向取消整块键盘 PCB，仅保留 XIAO nRF52840 Sense Plus 开发板，键轴通过软线连接主控。原来独立的 MCU、电源管理与 USB-C 占位移除，相关功能统一在开发板示意中展示。

开发板外形按 [Seeed 官方资料](https://wiki.seeedstudio.com/XIAO_BLE/) 的 21 × 17.8 mm 比例建模。官方确认 Sense Plus 配备 PDM 麦克风与 IMU。展示中的元件位置、高度和焊盘仅为示意，并非官方精确 CAD。USB 插拔空间、固定方式、麦克风声孔及天线净空尚未做工程验证。

轴体底部放置一组 10 个热插拔底座，其下为打印承托框组。用户已确认凯华 Kailh MX 热插拔底座，具体料号和尺寸尚待核对；承托框内孔 14.6 × 6.6 mm 是布局假设，没有实际锁止卡扣，也没有与外壳连接的结构，不能直接用于固定实物。新增的第 16 个 STL 是承托框位置试样，必须按底座型号调整后才能做装配件。也可改为轴体直接焊线方案。

蓝色与棕色软线仅表达底座到开发板的走线空间，**不是接线图**：端点不对应实际 GPIO，尚未确定矩阵或直连、二极管方向、旋钮及摇杆配线、供电方案和固件。不得按此展示焊线。线束可以独立隐藏，与电子层一起拆解；不进入打印包。

网页“仅看电子层”包含底座承托框，以展示底座与打印件的关系。尚未进行实际打印、插拔寿命、焊接和电气测试。


## v0.4 参考图布局修正（布局沿用）

对照仓库已有[官方正面参考图](research/assets/codex-micro-product.png)与[命令键参考图](research/assets/codex-micro-command-keys.png)，将原先错误的两排三列任务键改为四列骨架：第一排为旋钮、两枚任务键、摇杆；第二排四枚任务键；第三排快速模式、批准、拒绝、分支对话；第四排为左侧圆形触控区外观、居中双宽语音键、右侧发送键。

12 枚可见键帽对应 13 个轴体位置，语音键下方两轴。轴体、底座及承托框同步到新布局，XIAO 飞线结构保持。打印包现在有 18 个 STL，旧包和旧键号（尤其 key-10/key-11/key-12）不可混用。

键帽采用封闭凹面网格，凹面同步进入 STL。任务键的半透明材质、中心圆点、命令图标、旋钮斜槽和四角螺钉是渲染细节，不作为可装配结构。圆形触控区也仅为外观示意，没有实现触控电路。参考图用于布局和比例对照，110 mm 方形外壳、键距和高度均为自研设计假设，不能视为官方实测尺寸或 1:1 工程复刻。宽键的双轴固定、行程与稳定性仍待验证。


## v0.5 悬浮按键结构（当前）

取消原先 Z=17 的高位上盖及键帽轮廓孔，改为 Z=10、厚 1.5 mm 的低位轴体定位板，围框高度从 14 mm 降为 7 mm。键帽下沿仍在 Z=18，定位板顶面为 Z=11.5，因此按键侧面和轴体上部外露。定位板仍使用 `top.stl` 文件名，但结构与旧版不兼容。

定位板改为 13 个 14.2 mm 轴孔（宽语音键下两个），不再用上盖围住键帽。孔宽、板厚和卡扣适配仍是待验证假设；并非官方结构尺寸。XIAO、热插拔底座与飞线方案保留。外露式结构与最终固定、绝缘、支撑设计仍需实物检验。
